# Hello Moving — Visual Identity (V2.1)

## Logo — "Momentum"
An `H` whose crossbar is a bold, sharp, flat orange forward-arrow. Says *Hello* (H) + *moving* (→).
100% flat: solid fills only, no gradients, no glows, no shadows in the mark.
Files (assets/brand/):
- hm-icon.svg        primary, dark surfaces (white posts #EDEFE9 + orange arrow #F5A623)
- hm-icon-mono.svg   single-colour (currentColor) — black / white / orange
- hm-app-icon.svg    flat dark tile (#151812) + glyph, padded
- hm-favicon.svg     tile version, robust on any tab background
Horizontal lockup = mark + wordmark (Geist 700), built as a component after type lock.

## Colour hierarchy — 75 / 20 / 5 (orange is gold)
- 75%  charcoal / warm black    surfaces  #0C0E0B · #151812 · #1E221B
- 20%  white / typography       text      #EDEFE9 · #A9B0A3
-  5%  orange (precious)         accent    #F5A623 (hover #db8c10)  — NEVER floods
Orange is allowed ONLY on: primary CTAs, active nav, focus rings, the logo arrow,
one key number per view. Not on: backgrounds, body text, generic UI, borders.
No blue. No green except the LINE button (#06C755).

## Typography
Display / UI (Latin): GEIST (Vercel) — OFL / Google Fonts.
Data / labels / eyebrows: GEIST MONO.
Japanese: Noto Sans JP (pairing partner).
Rationale: engineered, minimal, timeless; purpose-built for a technology product;
tabular numerals for stats/pricing; deliberate (not the AI-default Space Grotesk).
